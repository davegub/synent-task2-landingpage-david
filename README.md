# LeadFlow — Real Estate Lead Follow-Up Landing Page

LeadFlow is a responsive landing page designed for a fictional real-estate lead follow-up service.

The page focuses on helping real-estate agents capture, respond to, and follow up with potential clients more effectively through an automated lead-management system.

This project was created as part of my **Synent Technologies Web Development Internship**.

## 📱 Responsive Testing

The landing page was tested across the following viewport sizes:

| Device Type | Viewport Width | Status   |
| ----------- | -------------: | -------- |
| Mobile      |          375px | ✅ Tested |
| Tablet      |          768px | ✅ Tested |
| Desktop     |         1440px | ✅ Tested |

### Mobile Testing

At mobile widths, the navigation changes to a hamburger menu.

The menu:

* Opens and closes correctly
* Animates between hamburger and X states
* Contains all primary navigation links
* Closes after selecting a navigation link
* Closes when the `Escape` key is pressed
* Restores focus to the menu button when closed with `Escape`

### Responsive Layout

* Proper spacing

* Usable buttons

## 🎯 Project Objective

The objective of this project was to build a clean, responsive, and functional landing page while demonstrating practical frontend development skills.

The LeadFlow concept was created around a real-world business problem:

> Real-estate agents can generate leads but lose potential clients when they fail to respond and follow up quickly.

The landing page communicates how an automated lead follow-up system could help address this problem.
